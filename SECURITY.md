# Security

## Reporting vulnerabilities

If you find a security issue in the **on-chain program** or settlement verification code in this repository, please report it responsibly:

- Open a [GitHub Security Advisory](https://github.com/1fair-labs/gift-draw-onchain/security/advisories/new) on this repo, or
- Contact the GiftDraw team through official channels listed on [giftdraw.today](https://www.giftdraw.today).

Do **not** open public issues for exploitable vulnerabilities before they are fixed.

## Scope

This repo covers Solana program logic and settlement math. The consumer app, treasury operations, and infrastructure are out of scope here.
