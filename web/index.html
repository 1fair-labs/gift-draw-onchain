Check a GiftDraw draw

Pick a draw and press Check. Your browser reads Solana directly and recomputes every hash itself, with the same code as the scripts in this repository. Nothing to install, no account, and nothing here has to be taken on our word.

Settings: Solana RPC and site

The public devnet RPC limits how fast one visitor may read. If a step stops with "429" or "Too many requests", wait a minute or paste an RPC of your own — any devnet endpoint works, and using one you chose means you are not trusting ours.

Draw ids are dates: YYYYMMDD, or YYYYMMDD_N when a day holds more than one. Prefer a terminal? The same checks run with npm run verify-… — see the README. Or ask an AI assistant to audit the code for you: ready-made prompt.
